# 윈도우 트랙패드 (WinTrackpad)

안드로이드 폰을 **Windows용 블루투스 트랙패드**로 만드는 앱입니다.
앱을 열고 PC와 블루투스로 연결하면 화면 전체가 흰색 트랙패드가 되고, 맥북 트랙패드처럼 제스처로 조작할 수 있습니다.

폰이 **표준 블루투스 마우스 + 키보드(HID)** 로 등록되기 때문에 **PC에는 아무것도 설치할 필요가 없습니다.**

## 요구 사항

- Android 9(API 28) 이상
- 블루투스 HID Device 프로필을 지원하는 폰 (삼성·픽셀 등 대부분 지원. 일부 제조사 폰은 막혀 있음)
- 블루투스가 있는 Windows 10/11 PC

## 제스처

| 제스처 | 동작 |
|---|---|
| 1손가락 이동 | 커서 이동 (속도에 따른 가속) |
| 1손가락 탭 / 두 번 탭 | 클릭 / 더블클릭 |
| 탭 후 바로 눌러서 이동 | 드래그 |
| 2손가락 탭 | 오른쪽 클릭 |
| 2손가락 이동 | 스크롤 (세로/가로, 관성 스크롤) |
| 2손가락 벌리기/모으기 | 확대/축소 (Ctrl + 휠) |
| 3손가락 탭 | 가운데 클릭 |
| 3손가락 좌우 | 앱 전환 (Alt+Tab, 손을 떼면 선택) |
| 3·4손가락 위 / 아래 | 작업 보기 (Win+Tab) / 바탕 화면 (Win+D) |
| 4손가락 좌우 | 가상 데스크톱 전환 (Ctrl+Win+←/→) |
| 4손가락 탭 | 알림 센터 (Windows 11: Win+N, Windows 10: Win+A) |

- 관성 스크롤 중에 손가락을 대면 스크롤만 멈추고 클릭은 되지 않습니다.
- 트랙패드 화면은 **가로**로 고정됩니다.
- 앱을 닫거나 화면을 꺼도 **백그라운드에서 연결이 유지**됩니다. 알림창의 알림을 누르면 앱으로 돌아오고, 알림의 **연결 끊기 / 종료** 버튼으로 끝낼 수 있습니다.
- 화면 아래 **큰 클릭 버튼**은 실제 마우스 버튼처럼 동작합니다. 짧게 누르면 클릭, 꾹 누른 채 다른 손가락으로 트랙패드를 움직이면 드래그입니다.
- 트랙패드 화면 오른쪽 위 **일시정지**는 연결을 유지하고 입력만 멈춥니다. **설정** 또는 뒤로 버튼을 누르면 연결을 유지한 채 설정 화면으로 갑니다.
- 탭 클릭, 탭 드래그, 2·3손가락 탭은 각각 끌 수 있습니다. 탭 클릭을 끄면 큰 클릭 버튼(왼쪽 클릭 / 끌기 고정 / 오른쪽 클릭)이 항상 표시됩니다.
- 진동은 클릭, 드래그 시작·끝, 다중 손가락 제스처, 연결, 전송 오류를 서로 다르게 알려 줍니다. (Android의 '터치 진동' 설정을 따릅니다.)

스크롤은 HID "Resolution Multiplier"를 사용합니다. Windows가 이를 켜면 1/120칸 단위로 부드럽게 스크롤되고, 켜지 않으면 자동으로 칸 단위로 보냅니다.

## 사용법

1. 앱을 열고 블루투스 권한(근처 기기)을 허용합니다.
2. **처음 한 번:** "PC에서 이 폰을 찾을 수 있게 하기"를 누른 뒤,
   Windows **설정 → Bluetooth 및 장치 → 장치 추가 → Bluetooth** 에서 폰 이름을 선택해 페어링합니다.
   - 예전에 이 폰을 PC와 일반 "휴대폰"으로 페어링한 적이 있다면 Windows에서 그 장치를 **먼저 제거**하고 다시 추가해야 합니다.
3. 연결되면 화면이 흰색 트랙패드로 바뀝니다.
4. 다음부터는 앱을 열면 마지막 PC에 자동으로 다시 연결합니다. (안 되면 '다시 연결' 버튼을 누르거나, PC의 블루투스 설정에서 연결하세요.)

연결 화면에서 포인터 속도, 스크롤 속도, 자연스러운 스크롤(맥 방식), 탭하여 클릭, 진동을 조절할 수 있습니다.

## APK 받기

`main` 브랜치에 푸시할 때마다 GitHub Actions가 단위 테스트, lint, 빌드를 거쳐 버전별 릴리스(`v1.1.N`)를 만듭니다. 이전 버전 릴리스도 남아 있습니다.

폰 브라우저에서 아래 주소를 열고 `WinTrackpad.apk`를 받아 설치하세요. (설치할 때 "출처를 알 수 없는 앱" 허용이 필요합니다.)

https://github.com/Cherrytastdonut/TrackPad/releases/latest/download/WinTrackpad.apk

### 업데이트 설치를 위한 고정 서명 키

같은 키로 서명된 APK끼리만 삭제 없이 업데이트할 수 있습니다. 저장소 **Settings → Secrets and variables → Actions** 에 아래 시크릿을 추가하면 CI가 고정 키로 서명합니다. 키 파일은 저장소에 넣지 않습니다.

| 이름 | 값 |
|---|---|
| `SIGNING_KEYSTORE_BASE64` | 키스토어 파일(.jks)의 base64 문자열 |
| `SIGNING_STORE_PASSWORD` | 키스토어 비밀번호 |
| `SIGNING_KEY_ALIAS` | 키 별칭 |

시크릿이 없으면 디버그 키로 서명되며, 이때는 업데이트 설치가 실패할 수 있습니다.

## 직접 빌드

Android Studio에서 이 폴더를 열고 ▶ 실행하거나:

```bash
./gradlew testDebugUnitTest lintRelease assembleRelease
# 결과: app/build/outputs/apk/release/app-release.apk
```

## 구조

```
app/src/main/java/com/example/wintrackpad/
├── MainActivity.kt   설정 화면, 권한, 흰 트랙패드 화면(가로)
├── HidService.kt     백그라운드 포그라운드 서비스, 알림, 자동 재연결
├── HidManager.kt     블루투스 HID 등록, 디스크립터, 순서 보장 전송, 세션·실패 관리
├── HidReports.kt     리포트 바이트·휠 누적 (Android 의존 없음, 단위 테스트 대상)
├── Haptics.kt        동작별 진동
├── TrackpadView.kt   멀티터치 → 제스처 해석 (가속, 관성 스크롤, 핀치, 스와이프)
└── Settings.kt       설정 저장
```

## 알려진 제한

- 제스처 내비게이션을 쓰는 폰은 화면 맨 아래 가장자리 스와이프가 홈 제스처로 동작할 수 있습니다. 좌우 가장자리는 가능한 범위에서 막아 두었습니다.
- 한 번에 하나의 블루투스 HID 앱만 등록할 수 있으므로, 다른 블루투스 키보드/마우스 앱은 종료해 두세요.
